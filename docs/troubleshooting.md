# Local execution notes

- **Windows HTTPS certificate failure:** the model downloader uses `truststore` to verify HTTPS against the Windows certificate store. Certificate checking remains enabled. Do not replace this with `verify=False`.
- **Several GitHub accounts in Git Credential Manager:** choose the intended existing account with `git -c credential.username=23022006muki -c credential.interactive=false push origin main`. Do not print credentials or put tokens in Git URLs.
- **6 GB GPU memory:** the XLM-R configuration enables gradient checkpointing and disables AdamW foreach temporary buffers. If a new run runs out of memory, lower its micro-batch size and increase accumulation to retain an effective batch of 32; use a new output directory and report the actual configuration.
- **Interrupted experiment:** `history.json` alone is not proof that an experiment finished. Completed runs have `total_seconds` in `run.json`; the notebook rejects reuse of a partial run. Check the actual process before starting another training job. A new run directory is required when retrying an interrupted configuration.
- **Mistral regex warning while loading local DistilBERT:** Transformers 4.57.6 can issue this warning for a local non-Mistral config without a `transformers_version` field. The downloaded approved model is DistilBERT and uses WordPiece. The current loader does not enable the Mistral regex patch. Do not blindly enable that patch for this BERT tokenizer.
- **Reproducibility:** seeds, file hashes, split hashes, configurations, model provenance, and the local dependency freeze are recorded. CUDA memory-efficient attention warns that it is not bit-for-bit deterministic; tiny numerical differences can remain across runs or hardware.
- **Offline Kaggle:** attach the competition and the exact approved model before disabling internet. Prepare the dependency versions listed at the top of the notebook. The notebook source contains no competition rows or ID split payload; it generates the audit and split from the attached data at runtime.
- **GitHub and data files:** source and aggregate reports can be pushed. Dataset CSVs, ID-level diagnostics, prediction CSVs, model binaries, and training logs remain local by default. An automatic approval review required explicit permission before publishing competition-derived ID artifacts.
