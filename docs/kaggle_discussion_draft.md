# UEL_SGS_LucViHoangDe_C1 — Approved multilingual encoder training code

Our team (UEL / SGS / Lục Vị Hoàng Đế) has made its Challenge 1 training code available here:

https://github.com/23022006muki/RMIT-Hackathon-2026

The repository contains a self-contained Kaggle notebook, approved-backbone encoder fine-tuning, group-aware validation by language and label, imbalance experiments, macro-F1 reports, and strict CSV validation. It uses the supplied competition data and the approved Kaggle DistilBERT/XLM-RoBERTa model sources. Each final notebook uses one approved backbone.

This post shares source code with all competition participants as required by Foundational Rules section 6(b). Model checkpoints, raw prompt data, and ID-level prediction files are not part of this code-sharing post. The code license will be declared before this draft is published.

No competition CSV submission is performed by posting this link.
